DIGITAL ACADEMY STUDIO WEBSITE
==============================

Files:
- index.html : Responsive website, SEO metadata, services, project library, upload preview and contact form
- logo.svg   : Custom lightweight logo and favicon

HOW TO OPEN:
Open index.html in a browser to preview the website.

HOW TO PUBLISH ON GITHUB PAGES:
1. Open your GitHub repository.
2. Upload index.html and logo.svg to the repository root (same level as README.md).
3. If GitHub asks, commit the files to the main branch.
4. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the Pages build and open the published URL.
